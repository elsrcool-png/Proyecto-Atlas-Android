# Cambios implementados

1. `atlasRegionSectors.js` define nombres, tipos, orden narrativo, imágenes y desbloqueos.
2. `atlasCanonicalWorlds.js` construye los nueve sectores de cada región.
3. `useAtlasSession.js` guarda sectores abiertos, bloquea rutas, migra guardados y exige Misión 14 para C3.
4. `ExploreMode.jsx` permite intentar una ruta bloqueada y muestra la explicación narrativa.
5. `SectorMapModal.jsx` muestra la grilla canónica y el boceto original.
6. `atlasMissions.js` usa tracker de jefe para v15, f15 y d15.
7. `atlasSave.js` migra de v1 a v2.
8. `Game.jsx` transmite al Modo Libre el estado canónico de sectores.
