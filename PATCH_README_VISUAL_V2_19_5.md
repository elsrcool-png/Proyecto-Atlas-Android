# Parche Atlas v2.19.5

Base obligatoria: **Atlas v2.19.4**.

Integra:

- normalización izquierda/derecha de héroes, mobs y jefes;
- caminata de cuatro apoyos en mundo libre;
- pasos y sombras de contacto en combate;
- actores de combate más grandes;
- facing dinámico de mobs y villagers;
- 16 NPC árticos maestros en cuatro direcciones;
- validación `npm run validate:v2-19-5`.

No aplicar sobre v2.19.3 o anteriores. Para esas versiones usar el ZIP completo.
