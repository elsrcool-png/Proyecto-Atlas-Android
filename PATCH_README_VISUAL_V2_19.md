# Atlas Visual v2.19

Versión consolidada de combate dinámico y audio de Región Verde.

## Recomendación

Usar el paquete completo cuando no exista certeza sobre qué v2.18 está instalada.

## Resultado

- Animaciones temporizadas conservadas.
- Daño y barras sincronizados con impactos.
- Audio sincronizado con cada golpe.
- Música y ambiente de Región Verde.
- Introducciones sonoras de enemigos.
- Controles de volumen.

Ejecutar:

```bash
npm run validate:v2-19
npm run build
```
