# Parche Atlas Visual v2.19.3

## Base requerida

Atlas Visual **v2.19.2 Orientación y Anclaje de Combate**.

No aplicar directamente sobre v2.19.1, v2.19.0, v2.18 o v2.17. Para cualquier otra base utiliza el paquete completo v2.19.3.

## Contenido

- integración de 20 NPC maestros de Región Verde;
- 80 sprites runtime con cuatro direcciones;
- alias visuales para Bren y Roland en entradas de dungeon;
- fallback procedural conservado para Vera la Cazadora;
- fondo maestro de combate de Región Verde;
- fondo de tundra para Región Ártica;
- arena especial para Aurel;
- nueva formación: enemigo izquierda, jugador derecha;
- orientación, desplazamientos, retrocesos, VFX y daño flotante adaptados;
- fondos anotados archivados como documentación, no usados directamente en runtime.

## Validación

```bash
npm run validate:v2-19-3
npm run build
```
