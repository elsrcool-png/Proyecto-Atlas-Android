# Atlas Visual v2.8 — Personajes y combate

Actualización sobre Atlas Visual v2.7.

## Incluye

- NPC propios para Reino Ártico y Reino Árido.
- 34 perfiles regionales diferenciados por oficio, silueta, ropa y accesorios.
- 9 héroes distintos: tres razas por tres clases.
- La misma identidad del héroe en selección, modo libre, dungeon y combate clásico.
- Animación melee conectada.
- Animación al fallar, incluyendo contraataque posterior cuando corresponde.
- Reacción e impacto del enemigo.
- Habilidades animadas según espada, daga, arco, bastón, lanza, hacha o martillo.
- Validador `scripts/validate-visual-v2-8.mjs`.

## Ejecutar

```bash
npm install
node scripts/validate-visual-v2-8.mjs
npm run build
npm run dev -- --host 0.0.0.0
```

El parche temporal de desbloqueo de v2.7 sigue siendo compatible.
